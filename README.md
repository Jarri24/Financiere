# Financiere App 📱💰

Aplicativo web progresivo (PWA) de finanzas personales, gestión de patrimonio, control de flujo de caja y seguimiento de micro-préstamos.

## Características

- 🔒 **Aislamiento Multi-Usuario:** Seguridad nativa con PostgreSQL Row Level Security (RLS) en Supabase.
- 💳 **Cuentas & Tarjetas Personalizables:** Cada usuario crea sus propios bancos, billeteras digitales (Yape/Plin), tarjetas y cuentas de inversión.
- 🏷️ **Categorías a Medida:** Categorías universales precargadas + creación instantánea en 1 clic de categorías personalizadas.
- 🤝 **Gestión de Préstamos:** Control de microcréditos a terceros con tasas mensuales y cobranzas de intereses.
- ⚡ **Automatización con Apple Pay / iOS Shortcuts:** Ingesta automática de consumos en segundo plano vía webhook REST.
- 📲 **PWA Instalable:** Experiencia de aplicación nativa en iPhone / Android sin pasar por App Store.

## Stack Tecnológico

- Frontend: HTML5 / Tailwind CSS / Vanilla JS (ES6+)
- Base de Datos & Auth: Supabase (PostgreSQL 15 + Row Level Security)
- Hosting: Vercel / GitHub Pages
